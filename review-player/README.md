# 审片播放器

朴素的 HTML 审片播放器，无框架、无后台、无构建步骤。直接用浏览器打开
`player.html` 即可（推荐用静态服务器，见下）。

## 文件

- `player.html` —— 主控页。左边画面（保留原生 `<video controls>` 皮肤、按钮、进度条），
  右边五行字，下面是入点/出点、倍速、跳转、切片进度条控件。
- `viewer.html` —— 只读镜像页。同一套播放器，控件整体禁用，只镜像主控页的时间和字幕。
- `src/engine.js` —— 纯逻辑核心（不依赖 DOM，可在 Node 里单测）：双播放头、双轨字幕、
  帧量化、最近亮过批注、倍速时钟。
- `src/player.js` —— DOM 绑定：引擎是时间轴/字幕唯一权威，`<video>` 只负责画面和声音。
- `src/data.js` —— 内嵌的两份 WebVTT 文本（与 `../review/master.vtt`、`notes.vtt` 逐字一致，
  测试会比对），以及素材参数。
- `src/sync.js` —— 两个页面之间的快照通道（BroadcastChannel，localStorage 兜底）。
- `serve.mjs` —— 零依赖、支持 Range 的静态服务器。
- `test/engine.test.js` —— `node --test` 单元/验收测试。
- `e2e/` —— 无头 Chromium 端到端测试与截图。

## 打开方式

需要走 http(s)，不要用 `file://` 直接双击打开：Chromium 系浏览器会用 CORS 拦截
外部 ES Module，而且跨页面同步依赖的 BroadcastChannel/localStorage 在 `file://` 的
不透明源下也不保证可用。本目录带了一个零依赖、支持 Range（视频 seek 必需）的静态服务器：

```bash
cd review-player
node serve.mjs          # 默认 8000 端口
# 主控页   http://127.0.0.1:8000/review-player/player.html
# 镜像页   http://127.0.0.1:8000/review-player/viewer.html
```

也可以用任意静态服务器（服务根目录建议取仓库根，使 `/review/master.mp4` 可访问），
例如 `python3 -m http.server 8000`。两个页面在同一浏览器里同时打开，五行字保持一致。

## 两套时间

- **切片播放头**：从这一段自己的 0 起算，0 = 入点，拖到头 = 出点。
- **成片播放头**：从成片零点起算，未划段时就是画面上烧着的秒数。
- 两者都能在同一快照里同时读到，关系是 `成片 = 入点 + 切片`。
- 所有内部时间按 25fps 量化到帧网格（40ms）。

## 两条字幕轨

| 轨标签 | 时间基准 | 文件里的时间是否被改写 |
| --- | --- | --- |
| 成片字幕 | 成片时间 | 否，按成片秒亮灭 |
| 审片批注 | 切片时间 | 否，批注文件里的 0.00–1.52 永远是切片的 0.00–1.52 |

- 半开区间 `[start, end)`：到 end 即灭（09.52 灭、20 秒灭同一条规矩）。
- 起点终点相同的零长 cue 再亮一秒。
- 跳转不会让被跳过的字幕“亮一下”，也不写“最近亮过”；只有连续播放扫过的批注才进记录。
- 重新划段会清空“最近亮过”，按新的一段重新累计。

## 划段与播放规则

- 入点 8.00、出点 14.00 时切片长 6.00 秒；入点改 10.00 后切片长 4.00 秒，播放头回到切片 0。
- 倍速对画面和声音同时生效（同一个 `playbackRate`）。
- 划段播放到出点即停在出点那一帧，声音随画面一起停，不进入出点之后的成片；
  “出点之后”这类字幕不会亮，也不进最近亮过。
- 未划段时倍速保持用户设定，整支 20 秒播到结尾才结束。

